# GeoScan Engineering

GeoScan Engineering is a geotechnical, geophysical, and field-investigation consultancy delivering data-driven solutions for civil works, infrastructure, mining, and environmental projects across Kenya and East Africa.

## Local preview

```bash
python3 -m http.server 8000 --directory public
```

Then open http://localhost:8000

## Project structure

- `public/index.html` — homepage
- `public/about.html` — company profile
- `public/services.html` — services and capabilities
- `public/approach.html` — workflow and methodology
- `public/gallery.html` — project gallery
- `public/contact.html` — contact page
- `public/style.css` — site styling

## Branding

The website is branded as GeoScan Engineering rather than eoScan.
